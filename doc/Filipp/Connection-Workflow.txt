NOTE ALL THIS INTERACTIONS COULD BE DONE BY MULTIPLE CLIENTS CONCURRENTLY


1. CLIENT: SEND NAME VIA REST -> SERVER REGISTERS CLIENT IN MEMORY
2. CLIENT: SEND GET_LOBBIES REQUEST VIA REST -> SERVER SENDS A LIST OF LOBBIES
3. CLIENT: CREATE LOBBY VIA REST/WEBSOCKET -> SERVER CREATES AND STORES A LOBBY IN MEMORY
4. CLIENT: JOIN LOBBY VIA WEBSOCKET -> SERVER ADDS CLIENT TO LOBBY
5. CLIENT: MULTIPLE CLIENTS START GAME WHEN READY -> SERVER CREATES A GAME INSTANCE AND STORES IT IN MEMORY

*SERVER NOTES
SERVER MUST STORE MULTIPLE CLIENTS
SERVER MUST STORE MULTIPLE LOBBIES
SERVER MUST STORE MULTIPLE GAMES
